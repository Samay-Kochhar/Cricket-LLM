# Batter-Bowler Matchup Contract

Labels: `ready-for-agent`

## What to build

Harden batter-bowler matchup questions such as “who dismissed this batter most,” “which bowler controls this batter,” and matchup leaderboards. Matchup answers should be grounded in delivery-level evidence and expose sample size or low-sample context.

## Acceptance criteria

- [ ] Named-batter matchup questions normalize to the correct matchup operation, entity, metric, grouping, and batter filter.
- [ ] Batter-bowler matchup leaderboards execute through the approved matchup executor.
- [ ] Matchup result columns include player dimensions, metric values, and sample-size context.
- [ ] Low-sample matchup results are flagged or explained.
- [ ] Unsupported matchup shapes return a clear unsupported response.
