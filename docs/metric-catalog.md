# ODI Metric Catalog

This document describes the initial v1 metric set for the ODI Analyst Workbench.

## Supported Query Classes
- Role and position comparison
- Strengths and weaknesses
- Head-to-head matchup
- Venue and context leaderboard
- Trend and progression analysis

## Initial Metrics
- `runs_scored`
- `batting_strike_rate`
- `dismissals`
- `boundary_percentage`
- `control_percentage`
- `economy_rate`
- `wickets_taken`
- `shot_share_percentage`

These metrics are defined in code in `backend/app/services/metric_catalog.py`.
