# Metric Definitions for LLM (Cricket IPL DB)

## 1. Legal Delivery

A delivery is considered **legal** (`is_legal_delivery = TRUE`) if it is NOT a wide and NOT a no-ball.  
Byes and leg-byes on a legal ball are still legal deliveries.

## 2. Dot Balls

We record three dot-ball perspectives:

- `is_dot_ball_team_view`  
  - TRUE if the delivery is legal and the batting team scores 0 runs in total (`runs_total = 0`).
- `is_dot_ball_batter_view`  
  - TRUE if the delivery is legal and the batter scores 0 runs from the bat (`runs_batter = 0`).  
  - Byes/leg-byes still count as 0 runs off the bat.
- `is_dot_ball_bowler_view`  
  - TRUE if the bowler concedes 0 runs by our definition (`runs_conceded_bowler = 0`), i.e. no runs off the bat, no wides, no no-balls.

## 3. Runs Conceded by Bowler

`runs_conceded_bowler = runs_batter + wides + no-balls`

Byes and leg-byes are NOT included and are not counted against the bowler.

## 4. Phases

Each ball has a `phase`:

- `"powerplay (file)"` – based on powerplay info from the match JSON.
- `"middle (derived)"` – overs after powerplay up to over 15.
- `"death (derived)"` – overs from the 16th over onwards.

(You can adjust the overs here if you changed the rule.)

## 5. Wicket Credit

`dismissal_bowler_credit = TRUE` for dismissals normally credited to the bowler  
(e.g. bowled, lbw, caught, stumped, hit wicket, caught & bowled).  
Run-outs and other non-bowler dismissals have `dismissal_bowler_credit = FALSE`.

## 6. Strike Rate and Economy

- **Batting strike rate**:  
  `SR = 100 * runs / balls_faced`  
  where `balls_faced` counts only legal deliveries faced by the batter.

- **Bowling economy**:  
  `Econ = 6 * runs_conceded / balls_bowled`  
  where `balls_bowled` counts only legal deliveries bowled.

- **Team strike rate in a phase**:  
  `100 * phase_runs / phase_balls_faced`

- **Run rate in a phase**:  
  `6 * phase_runs / phase_balls_faced`

## 7. Matchup Definitions

In `batter_bowler_matchups`:

- `balls` – number of legal deliveries where this bowler bowled to this batter.
- `runs_off_bat` – runs the batter scored off the bat against this bowler.
- `runs_conceded` – total runs this bowler conceded in this matchup (including extras).
- `wickets` – number of times this bowler dismissed this batter (where `dismissal_bowler_credit = TRUE` and `dismissal_player_out = batter`).

Derived metrics:

- `strike_rate_vs_bowler = 100 * runs_off_bat / balls`
- `batting_average_vs_bowler = runs_off_bat / wickets` (if wickets > 0)
- `balls_per_dismissal_vs_bowler = balls / wickets` (if wickets > 0)
